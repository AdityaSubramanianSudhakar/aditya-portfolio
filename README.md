# Aditya Subramanian Sudhakar — Portfolio

A lightweight, responsive portfolio website built with plain HTML/CSS/JS.

## Quick start
1. Extract the ZIP.
2. Open `index.html` in a browser.

No Node.js or installation is required.

## Included
- Light premium responsive design
- Subtle glassmorphism
- Your profile photo
- View/Download Resume buttons
- About, projects, skills, journey, certifications and contact sections
- GitHub, LinkedIn and email links
